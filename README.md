# create-cove

CLI for creating projects with the Cove Stack.

```bash
pnpm create cove
```

## Templates

- [`default`](https://github.com/mugnavo/cove) - Minimal Cove Stack template
- [`monorepo`](https://github.com/mugnavo/cove-monorepo) - Cove Stack Monorepo via pnpm workspaces
